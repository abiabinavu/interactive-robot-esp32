# ESP32 Interactive Robot

An interactive personal robot built around ESP32 and programmed in Embedded C. The project integrates sensors and output peripherals so the robot can respond to user interaction in real time.

## Project overview

The firmware connects sensor inputs with output-device control, bringing hardware and software together in an embedded system.

## Technical focus

- ESP32 microcontroller
- Embedded C firmware
- Sensor interfacing
- Output peripheral integration
- Real-time interaction
